# Conector local de agentes (superseded)

Este fluxo foi aposentado. Não use instruções de ponte local, sincronização de
rascunhos ou comandos do repositório para editar conteúdo.

Para o fluxo atual, editores devem usar o dashboard com o processo file-first
de exportação/importação ou um assistente conectado ao rascunho canônico. Para
implementação, consulte o [dossiê V2](plans/ai-content-editor-v2-revision-8/README.md)
e o [pacote MCP standalone](../packages/content-mcp/README.md).
